deepcove runs Claude Code and Codex in their own VMs, and you drive them from a browser on any device. Your
first one takes three steps.

<Steps>

1. **Install**

   One command on macOS or Linux. It starts deepcove in the background.

   ```sh
   curl -fsSL https://deepcove.dev/install.sh | sh
   ```

2. **Open the dashboard**

   It opens in your browser, on this machine only. On a machine you reach over SSH, see
   [Install](/get-started/install/#open-the-dashboard).

   ```sh
   deepcove open
   ```

3. **Start a session**

   Click **New session**, pick an agent and a folder, and the agent starts in its own VM.
   [Your first session](/get-started/first-session/) walks through the dialog.

</Steps>
